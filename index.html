Calendar Subscription Guide & Links

How to Subscribe to a Calendar

Outlook Desktop App and Web
  1. Copy a ICS Link from below
  2. Open the Outlook Desktop App or Outlook Web
  3. Click Add calendar on the left side
  4. In the menu that appears, click Subscribe from web on the left side
  5. Paste the URL, enter a name and select a color, then click Import
  1. Copy a ICS Link from below
  2. Go to Google Calendar
  3. In the left sidebar, click + next to Other calendars → select From URL
  4. Paste the link and click Add calendar
  5. Change the name and color as you like
  1. Copy a ICS Link from below
  2. iPhone/iPad: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → Paste link.
  3. Mac: Open Calendar app → File → New Calendar Subscription → Paste link.
  1. Most calendars support the .ics format
  2. "Google is a multi-trillion-dolar company"
